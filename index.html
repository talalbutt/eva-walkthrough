Running it in class

→ Space Page Down next beat. ← Page Up back. Home restart. End show everything. 1 to 5 choose a problem. A click on the chart also moves on.

Every number in the problem can be typed over; the chart and the working follow. With "Pause before answers" on, each step first shows the question and the formula, then the answer.

ETC follows the course formula sheet: estimate time to complete = original time ÷ SPI. The plan line is straight, as the sheet's PV formula assumes.

Created by Dr. Talal Butt, Higher Colleges of Technology, Fujairah (tbutt@hct.ac.ae), for CIS 3603 Project Management. The worked problems come from the CIS 3603 course materials.

Set in Barlow and Literata, both under the SIL Open Font Licence, embedded in this file. No network is used.
